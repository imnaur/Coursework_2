# Проект "Курсовая работа 2 | Поиск вакансий на hh.ru"

##
**Проект "Поиск вакансий на hh.ru" - это новый разработанный проект для онлайн-поиска, который показывает актуальные данные о вакансиях из сайта hh.ru .**

## Установка
1. Клонируйте репозиторий:
```
https://github.com/imnaur/skypro.git
```

2. Установите зависимости через Poetry:

```
poetry install
```
## Использование:

1. Начните поиск с одного слова, введя ключевое слово в поисковик.
2. Дополните ключевые данные: заработную плату, сколько вакансий Вы хотите увидеть.
3. При появившемся "Вакансии: " примите актуальную информацию сайта с указанием ЗП.
